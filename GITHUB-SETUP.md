# Push this project to GitHub

Create an empty GitHub repository named `TogetherScreen`, then run these commands from this folder:

```bash
git init
git add .
git commit -m "Initial TogetherScreen release"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
